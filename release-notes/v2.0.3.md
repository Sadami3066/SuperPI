# Super PI Agent 2.0.3

## 超级模式与多设备协作

- 打开抽屉，在顶部一键切换到超级助理模式，让一个对话负责拆解任务、安排助手并把结果汇总回来。
- 在「团队」里选择哪些 Bot 可以参与协作，每个 Bot 最多保留 5 个后台工作助手，并能看到当前占用了几个名额。
- 超级助理会把任务分成阶段，派给本机或已配对设备上的工作助手，进展、步骤和结果卡片实时回到聊天里。
- 点开工作助手即可查看它正在做什么、回答它的问题、补充消息、切换模型或停止它，不必回到主对话。
- 工作助手等待确认或仍在运行时可以继续输入，消息会排队，等它恢复或完成后按顺序送达。
- 「归档并重置」会把当前协作对话存档并开启一段干净的新对话，已经保留的工作助手仍然在团队里。
- 远程设备断线、任务取消或超时后会自动清理未完成的步骤和临时文件，不会留下半截状态。

## 长期记忆升级

- 记忆页重做为「档案」「关系」「时光」三页，分别对应长期档案、人物与关系和近期事件。
- 活档案支持置顶、归档、新建和编辑；人物与主题支持别名、一句话介绍、关系连线和重复条目合并。
- 近期事件与待办按即将到来、今天、本周、本月和更早分组，可标记完成、修改、置顶或删除。
- 深层记忆索引保留更早的资料，助手需要细节时会主动检索，不把所有内容一次塞进对话。
- 记忆动态记录每一次自动或手动改动，可以逐条撤回；也可以立即整理或导出全部记忆。
- 记忆设置可以分别调整活档案、人物与关系、近期事件、深层索引的注入配额，一键恢复自动分配。
- 每个 Bot 可以选择使用全部记忆、只使用工作学习记忆或关闭记忆，不同助手之间互不串味。
- 某段对话可以设为「不记入记忆」，也可以一并清除这段对话已经产生的记忆。
- 配对中继后，记忆会在多台设备之间增量同步；首次切换账号时会询问合并还是替换，避免误删另一台设备的记忆。

## 对话、定时与小程序

- 长对话顶部新增「加载更早」，历史消息分段载入，打开长会话不再一次渲染全部内容。
- 定时任务投递失败时会在列表里直接显示原因，并提供一键重试；临时失败会自动退避重试。
- 修改时区、重启手机或更新 App 后，每日提醒会按新的本地时间重新计算，过期的一次性提醒会自动清理。
- 从登录回调返回 App 时不再误跳到文件分享页面。
- 离开小程序预览时会自动释放语音朗读和识别资源，避免后台继续占用麦克风或扬声器。
- 小程序写入或导入前会先检查可用空间，失败后清理残留文件，不再留下半截数据。
- 复杂搜索也做了超时保护，界面不会因为一次搜索长时间无响应。
- 虚拟屏文字输入在受限机型上会给出更清楚的原因和下一步提示，而不是只显示失败。

## 插件与体验优化

- 飞书和企业微信插件增加了安装包完整性校验失败提示，并对日志中的账号和授权链接信息做了脱敏处理。
- 小米云服务插件在参数校验失败时会给出更明确的调整提示，不再笼统提示缺少信息。
- 高德地图和滴滴出行插件卡片在无法打开插件页时会弹出提示，不再静默无反应。
- 中山大学插件会区分「状态读取失败」与「验证码错误」，避免在登录已通过时误提示验证码无效，也不会在状态刷新失败时误报就绪。
- 赞噢校园集市刷新帖子列表时会保留当前列表并显示加载指示，不再整页闪烁重建。
- 官方与个人插件统一了文案、卡片和重试体验，去掉多余提示和内部术语，失败时只说发生了什么、可以怎么做。

## 安全、稳定与性能

- 本机无线调试通道增加了双向身份校验，每次重启都会更换密钥，其他应用无法冒充或窃听本地连接。
- 切回普通模式或关闭无线调试时，后台调试服务会主动关闭，不再继续留在后台。
- 超级模式的任务记录只更新变化的部分，工作助手很多时界面也不会反复整表重载。
- 长对话滚动和刷新更稳，定时任务与文件浏览的打开速度更快，翻页不再反复等待。
- 插件升级后会清理旧的缓存包，长期使用不再堆积无用文件。
- 加固并清理了正式包的混淆保留规则，确保核心功能、虚拟屏与插件运行在正式版中稳定可靠。

# Plugin development

The canonical, current plugin development guide is maintained in the host repository at https://github.com/Sadami3066/SuperPI-App/blob/master/docs/PLUGIN_DEV.md. It covers the host contract, the `plugin.json` manifest, the `.ddp` package format, signing and verification, install and update, lifecycle, extension points and the security model.

To start writing a plugin, copy [`template/`](../template/). Marketplace listing rules and the entry review checklist live in [`MARKET_POLICY.md`](../MARKET_POLICY.md) and [`PR_REVIEW.md`](../PR_REVIEW.md).
